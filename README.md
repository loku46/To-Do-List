# 📝 To-Do List App

A simple and beginner-friendly **To-Do List web application** built using **HTML, CSS, and JavaScript**.  
This project helps users add, complete, and delete daily tasks while learning the basics of front-end development.

---

## 🚀 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Clean and simple UI
- Beginner-friendly project structure

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the app  
- **CSS3** – Styling and layout  
- **JavaScript (Vanilla JS)** – Functionality and DOM manipulation
